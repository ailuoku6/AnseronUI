# Ljump

基于 AnseronUI 的 macOS 窗口工作组工具。透明浮层停靠屏幕右侧，鼠标触边滑出，离开后收起。双击启动后显示工作组；菜单栏也提供「显示工作组」和退出入口。

默认提供「需求」「bug」「学习」三个工作组。升级时只迁移尚未改名的旧默认组，保留窗口、提醒、颜色和优先级；自定义组名继续保留。

把应用窗口拖入右侧工作组或「＋」后，原窗口会回到本次拖动开始前的位置，窗口大小保持不变。拖到「＋」时立即归位，再填写新工作组；未落到工作组或「＋」的普通拖动不归位。工作组之间拖动窗口卡片也不会改变原窗口位置。

## 直接使用

打开 `dist/Ljump.app`，无需终端、Node.js 或开发服务器。首次使用，在 Ljump 菜单栏菜单中打开权限设置：

- **辅助功能**：切换到指定应用窗口、取消最小化。
- **屏幕录制**：用 ScreenCaptureKit 取得窗口缩略图；截图仅驻留内存，不保存到磁盘。

辅助功能入口为「系统设置 → 隐私与安全 → 设备控制和数据访问」（部分 macOS 版本名称为「辅助功能」）。若开关已经打开仍提示未授权，可能是之前构建的签名已失效：移除旧的 Ljump / App 条目，点击 `+`，按 `⌘⇧G` 选择当前 `dist/Ljump.app` 后重新开启，并退出重启 Ljump。应添加最终应用，不是 `.verification` 中的临时构建。Touch ID 或系统密码验证须由本机用户完成。

把应用窗口的标题栏拖到屏幕右侧，进入浮层后出现跟随鼠标的缩略图。松手到已有工作组即可加入，松手到加号可命名并创建新组。普通内容选择拖动不会被当作窗口拖动：Ljump 会检查目标窗口是否实际移动。

悬停工作组向左展开窗口列表；窗口较多时可滚动。点击窗口或按回车切换，最小化的窗口会先恢复再置前；上下键选窗口，左右键切换工作组，Esc 关闭编辑或收起浮层。右键工作组设置名称、颜色和优先级，数字越大越靠前。

## 窗口提醒

窗口加入工作组后，展开工作组并点击窗口卡片上的铃铛图标。图标有 VoiceOver 标签；有提醒时显示带标记的铃铛。

- **倒计时**：输入分钟数，或选择 5、15、30、60 分钟；支持小数分钟。
- **指定时间**：使用系统月历选择日期，点击小时或分钟后通过步进按钮、方向键或输入数字调整时间。
- 点击右下角的勾选图标保存；未设置的窗口不提醒，也不会主动申请通知权限。
- 再次点击铃铛可修改时间，点击面板底部明确的「取消提醒」按钮取消提醒。每个窗口最多保留一个提醒，更改时间会替换旧提醒。

首次保存时允许 Ljump 发送系统通知。到时通知显示工作组和窗口名称，点击通知切换到对应窗口。通知的横幅、声音和专注模式行为遵循 macOS 的通知设置。

提醒设置在本机保存，由 macOS 调度，不为每个窗口创建定时器。Ljump 运行时检测到窗口关闭、移出工作组或工作组被删除，会取消该窗口的待发通知并清理已送达通知。退出 Ljump 后系统仍可发送已安排的通知，但无法继续监测窗口关闭；下次启动会重新核对并清理失效记录。

## 移动与移出窗口

- **移动到工作组**：把窗口缩略图拖到右侧的目标工作组。移动会保留提醒。拖到加号可创建工作组，拖到空白处松开可取消。
- **移出工作组**：点击缩略图右上角的「×」。Ljump 会解除分组并取消提醒，原应用窗口继续保持打开。

工作组设置使用 AnseronUI TSX 表单、颜色选项和优先级加减按钮。勾选保存，叉号放弃修改；删除工作组需要在面板内再次确认。编辑期间浮层保持打开，Esc 可退出编辑。

## 窗口卡片与实时信息

窗口列表显示应用图标与名称、大幅预览、真实窗口标题及提醒状态。卡片右上角移出分组，右下角设置提醒，设置面板的蓝色勾选使用扁胶囊按钮。

展开列表时读取当前窗口信息，可见期间约每 2 秒更新。macOS 的 Window Server 标题和辅助功能 `AXTitle` 是信息来源；`AXDocument` 存在时可提供文稿路径。Cursor / VS Code 标准标题中的项目名称单独标注，Chrome 等浏览器的窗口标题通常对应当前标签页。没有公开项目名称的窗口仅显示实际标题，无法保证所有应用都提供同样详细的信息。

读取辅助功能信息在后台工作线程进行，使用较短超时，不扫描整棵辅助功能树。收起列表、切组、窗口关闭和取消订阅会取消任务并释放缓存；不会为每个窗口新增定时器，也不持久化采集到的文稿路径。

所有弹窗、窗口工具栏和工作组表单均由 AnseronUI TSX 的 View、TextInput、Button、Image 和 ScrollView 实现，支持浅色和深色外观。图标使用打包的 SF Symbols 图片资源；Swift 仅负责窗口识别与激活、截图、权限及系统通知等平台能力。

## 窗口生命周期

监视器按 **窗口 ID + 进程 ID** 跟踪窗口。两次连续完整系统窗口列表中缺失后发送关闭事件，通常约 1 秒内从界面和保存的工作组中移除。隐藏窗口仍保留。如果点击时发现窗口已关闭，Ljump 会立即清理并短暂显示提示。清空工作组、取消订阅或应用退出时释放定时器和事件回调。缩略图组件卸载或拖放结束时取消截图任务、清空 NSImage、关闭拖动预览。

窗口激活先确认窗口 ID 仍属于原进程，再通过当前位置和尺寸匹配辅助功能窗口；只有标题唯一时才使用标题回退，避免同名窗口误激活。

## 开发和打包

应用使用专属的叠放窗口与向左切换图标，macOS 版本保留圆角底座之外的透明区域。`assets/icons/app.svg` 和 `menubar.svg` 是可编辑源文件；菜单栏图标按系统 template 图像渲染，自动适配浅深色外观。

重新导出图标时，先在框架仓库根目录安装开发用栅格化工具，再在应用目录运行 `npm run icons`：

```sh
npm install --prefix .verification/ljump-icon-tools --no-save --no-package-lock @resvg/resvg-js
```

打包器将 `app-macos.png` 生成包含 16–1024 像素多尺寸图像的 `AppIcon.icns`；无需在用户电脑上安装图标开发工具。

在本目录运行：

```sh
npm run check
npm run typecheck
npm run package:macos
open dist/Ljump.app
```

打包生成 Release AOT 应用，复制到 `dist/Ljump.app` 并验证签名。Apple Silicon 构建主机需要 Xcode；应用最低支持 macOS 14。跨机器公开发布请使用 Developer ID 签名和公证，见仓库构建文档。

在开发机上可设置 `LJUMP_LOCAL_SIGN_IDENTITY` 为 `security find-identity -v -p codesigning` 列出的 Apple Development 签名身份，再运行 `npm run package:macos`。持续使用同一签名身份和应用路径，避免每次重编译后临时签名的散列变化造成授权失效。从临时签名切换到开发证书后，需要重新添加当前 `dist/Ljump.app` 一次。

`npm run build:macos` 生成 Debug 版，`npm run macos -- --no-build` 启动该调试产物。新构建之前应退出正在运行的旧 Ljump，否则 macOS 可能继续显示旧进程。

通用的 `app.macosAgent` 配置由 AnseronUI 打包器生成 `LSUIElement`。热区、窗口识别、截图、切换、生命周期管理由本应用的 `platforms/macos` 实现。
