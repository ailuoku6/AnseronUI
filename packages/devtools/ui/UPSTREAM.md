# UI provenance

The React panel components, styles.css, tree.ts, protocol.ts, curl.ts, copy.ts and
editHints.ts are adapted from ailuoku6's kuikly-devtools (MIT), version 1.0.7:
https://github.com/ailuoku6/kuikly-devtools

The original visual implementation is retained. Branding, unsupported capability
controls, and the AnseronUI protocol adapter/store are the local adaptations.
These are Node-served development assets, never application production assets.
