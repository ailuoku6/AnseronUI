# 需求与范围

## 用户目标

将 AnseronUI 项目用于开源，中文整理使用方法、支持能力，并提供独立的架构原理文档与 `.gitignore`。

## 范围

- 根 README、`docs/` 索引/专题、iOS/Android/Layout 包文档。
- 架构：TSX lowering、AOT、Core、协议、布局/测量、事件、路由、Module、ref、动画、线程和生命周期。
- 依据实际构建脚本完善忽略规则，说明第三方源码与本地产物的边界。
- 历史设计加定位说明，保留历史验证证据，修正公开文档中的本机绝对路径。

## 非目标

- 不增加框架运行能力，不改应用逻辑或编译器。
- 不发布 npm 包、不提交/推送 Git、不代选开源许可证。
- 不翻译第三方原始许可证、README、贡献指南或变更日志正文。

## 验收

- 中文首页可进入全部公开使用指南，命令与当前脚本一致。
- 支持范围包含基础组件属性/事件、触摸传播、动画、路由、返回键和原生扩展，并说明限制。
- 架构原理和 `.gitignore` 解释与源码及实际规则对应。
- 本地链接、示例类型检查与现有快速验证通过。

## 2026-11-08 补充要求

- 解释 TSX 改动为何更新 Core、是否每页有独立 Core，以及独立预编译框架的可能方案。
- 显式标注原生编译基于 scriptc、布局计算基于 Flexily。
- 参考官网 limitations / compatibility，同时核对固定 0.4.8 与项目补丁，提供业务 TS/TSX 写法限制。
