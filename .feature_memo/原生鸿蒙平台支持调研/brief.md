# 需求说明

用户希望项目支持原生鸿蒙（非 Android）App，先调研并写详细技术文档，随后要求利用已安装模拟器验证 scriptc/runtime，最低兼容 HarmonyOS 6.0.1 / API 21。

范围：源码/历史/官方资料审计，架构、工具链/runtime、Renderer、生命周期/服务、插件/CLI、风险、分阶段验收。

当前范围增加：实验性 OHOS archive 构建、设备运行和 Core 协议回放，保存可复现命令与证据。正式 Renderer、HAP 集成和签名发布仍未实施，不把 Android/WebView 当原生支持。

验收：文档入仓，来源/改造入口可追溯，P0 Go/No-Go 明确，区分事实/建议/未验证，保留其他未提交工作。

已锁定 SDK/设备组合和最低 API：DevEco 6.0.1.251、SDK 6.0.1.112、Mate 70 Pro arm64 API 21。首发能力和正式产品化排期仍待后续实施。
