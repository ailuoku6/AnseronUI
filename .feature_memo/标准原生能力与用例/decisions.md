# 决策
- 2026-11-10：长轮询复用现有异步与取消机制，避免新增原生传输消息类型。
- Web 不模拟安全存储；能力查询返回 false。
- 文件以不透明句柄传递；上传下载宿主执行，页面退出清理。
- 原生标准方法优先，原 device.info 示例仍可与 device.getInfo 共存。

- 2026-11-10：模拟器构建启用临时签名，Keychain 实测未签名被拒绝；无需开发团队。

- 2026-11-10：用户确认追加推送、后台任务、蓝牙、NFC，随后明确先不接支付；无需继续追问支付渠道。
- 推送／后台结果采用持久收件箱 + 显式确认消费，避免通过状态订阅合并而丢事件。
- 不伪造供应商 token、不使用页面定时器冒充系统后台调度，能力查询体现平台限制。APNs/NFC entitlement 模板仅作签名配置示例，不写入默认模拟器签名。
- UNUserNotificationCenter delegate 回调标为 nonisolated 并派发主线程，避免系统回调队列访问应用收件箱的 actor 状态。
