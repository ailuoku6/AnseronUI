# Brief

用户明确实施原评估第三项“性能验证覆盖整条渲染链路”和第四项“页面保活后的生命周期和内存策略”；虚拟列表必须支持可变高度。

验收：5000 条不等高文本仅挂载视口附近；动态行高、插入锚点、深处跳转和宽度变化正常；隐藏页面暂停计时器/动画/媒体，恢复保留状态；容量限制和内存压力能释放隐藏页面；有可复跑的 JS/native/Wasm 和真实 UI 验证及报告。

不扩展插件体系、字体管线或进程级状态序列化。

## 最终验收（2026-11-13）

授权范围已落地并验证。性能门槛覆盖协议吞吐与节点/缓存预算，真实平台功能通过；没有将其表述为所有设备的帧率或内存无泄漏保证。UIKit 大列表专项、移动 FPS/RSS 和 iOS27 UIScene 迁移留作后续独立工作。
